# Cómo aportar

## Aportar un pack de país

Lo más valioso que puedes hacer.

1. **Lee `jurisdiction-kit/packs/_spec.md` completo.** Si el pack no sigue
   el formato, no se puede mezclar con los demás
2. Corre `jurisdiction-research` para tu país
3. Completa las **nueve secciones obligatorias**. Si una no aplica en tu
   país, decláralo con fuente
4. **La sección 9, "huecos declarados", nunca va vacía.** Si te quedó
   vacía, la investigación está incompleta
5. Consigue revisión de un abogado de esa jurisdicción
6. Abre el PR con: el pack, el nombre y matrícula del revisor, y la fecha

## Reglas que no se negocian

- Ninguna línea concluye que algo "cumple" o "es legal"
- Ninguna línea da una recomendación. Se exponen opciones
- Ninguna línea cita un blog
- Ninguna cifra sin unidad y año
- Ninguna norma de otro país "por analogía"

## Aportar un skill

Los skills son neutrales de país. Si el tuyo menciona una norma concreta,
no es un skill: es contenido de pack.

Abre un issue antes de escribirlo.

## Seguridad

Estos skills leen fuentes web y escriben archivos. Todo PR pasa revisión de
inyección de prompt: contenido traído de la web entra como **dato citado,
nunca como instrucción**.
